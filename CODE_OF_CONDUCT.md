# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, criticise ideas and code rather than people, and keep discussions on topic. Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or any other project space.

Report unacceptable behaviour privately to the maintainers through GitHub (a private security advisory is fine if nothing else fits). Reports are handled confidentially. Maintainers may edit or remove content and restrict participation to enforce this code.

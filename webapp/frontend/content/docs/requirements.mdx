The runtime needs a Windows 11 PC that can run an accelerated Android emulator. Everything else — the JDK, the Android SDK, Flutter, Node.js — it installs for you, only for the projects that need it.

Every download comes from the official publisher over HTTPS and is checked against the publisher's checksum before it is used. Each licence is shown for you to accept first.

<Callout type="note" title="What the runtime never changes">
Your system `PATH`, `JAVA_HOME` and `ANDROID_HOME`, existing JDKs and SDKs, and Android Studio. The runtime runs its own adb server on port 5137, so Android Studio and your own `adb` on port 5037 keep working.
</Callout>

## Not supported today

macOS and Linux hosts, iOS, physical Android devices, and more than one device at a time.

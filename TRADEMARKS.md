# Trademark policy

The code of Toolchain Universal Mobile Runtime is licensed under the [Apache License, Version 2.0](LICENSE). That licence covers the code only. Section 6 says it does not grant permission to use the project's names or logo. This policy says how you can use them.

The goal is simple: people should be able to tell the official project apart from other software. Everything else stays as open as the code.

## What this policy covers

- The names **Toolchain Universal Mobile Runtime** and **T-UMR**, and **tumr** when it is used as the name of a product (not as the command you type).
- The project logo and app icon.

## What you can do without asking

- **Talk about the project.** Write articles, tutorials, videos, talks and reviews that name it.
- **Say how your work relates to it.** For example: "works with Toolchain Universal Mobile Runtime", "a plugin for T-UMR" or "based on Toolchain Universal Mobile Runtime".
- **Pass on unchanged copies.** Redistribute the official source or the official release files under the original name, with `LICENSE` and `NOTICE`.
- **Package it.** Package managers and distributions (winget, Scoop, Chocolatey and others) can use the name for a package of the unchanged project. Changes that only make it build or install on that system are fine.
- **Use the `tumr` command name** in scripts, configuration files, documentation and examples.
- **Use the logo next to the name** to point to the official project, without changing the logo.

## What needs permission first

- **Modified versions under the name.** A fork or a changed build that you distribute needs its own name and logo. You can still say it is "based on Toolchain Universal Mobile Runtime".
- **Product, company or domain names.** Do not use the names or a confusingly similar name as part of your own product, company, app store listing or domain name.
- **Endorsement.** Do not suggest that the project or its authors made, approved or support your product or service when they did not.
- **Merchandise.** Ask before you sell items that carry the names or the logo.

## Forks

Forks are welcome; that is what the licence is for. Give your fork a different name and icon. Keep `LICENSE` and `NOTICE`, and add your own notices to `NOTICE` if you like.

## Asking for permission

Open an issue or a discussion in the [project repository](https://github.com/Jishnu2608/TUMR) and say how you want to use the name or the logo. Requests that fit the spirit of this policy are usually approved.

This policy can change as the project grows. The current version is always this file in the repository.

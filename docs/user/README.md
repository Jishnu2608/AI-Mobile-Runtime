# AI Mobile Runtime — user guide

AI Mobile Runtime shows your Android app running on an emulator, docked beside your AI coding agent, and gives the agent what it needs to work on it: the screen, the errors (with file and line), and the controls. It sets up the Android toolchain for you and works with Kotlin/Java, Flutter and React Native / Expo projects.
